What the video shows

  1. The user opens KamiTrack and taps Start run.
  2. GPS recording begins — live map, distance and pace.
  3. The screen is locked. An ongoing notification stays visible for the whole run, so the location work is noticeable to the user while they are not in the app.
  4. Returning to the app, the distance and time have advanced — the route was recorded continuously.
  5. The user taps Finish and the service stops.

Why the permission is needed

KamiTrack records outdoor runs. Without a foreground location service the route breaks up the moment the screen turns off, which is most of any real run. The service starts only when the user taps Start run, is visible as an ongoing notification throughout, and stops when the run is finished or discarded.

The recorded route is shown to the user. It is never shared unless they choose to post it, and a shared post carries only a normalised shape — no real coordinates.
