# Local web fonts

Unmodified Latin WOFF2 subsets from Google Fonts, downloaded on 2026-10-22. Funnel Display and Funnel Sans are licensed under the SIL Open Font License (`funnel-OFL.txt`). Filenames contain the first 12 hexadecimal characters of their SHA-256 content hash.

Why Funnel: the site follows the terowong direction (see `DESIGN.md`). Funnel Display's letters are cut with funnel-shaped notches, which echoes the hole and the tunnel; Funnel Sans keeps body text in the same family.

CSS source: https://fonts.googleapis.com/css2?family=Funnel+Display:wght@300..800&family=Funnel+Sans:wght@300..800&display=swap

- Funnel Display, variable 300 to 800: https://fonts.gstatic.com/s/funneldisplay/v3/B50WF7FGv37QNVWgE0ga--4Pbb6dDYs0gnHA.woff2
- Funnel Sans, variable 300 to 800: https://fonts.gstatic.com/s/funnelsans/v3/OpNIno8Dg9bX6Bsp3Wq69TpyfhjoyU7d.woff2
